使い方

通常使うのは電源スイッチと4 つのボタンだけです。PROFILE ボタンは、接続先を切り替えるときと、設定を消すときに使います。

  1. 01ボタンを押す
  2. 02USB でつなぐ
  3. 03ワイヤレスでつなぐ
  4. 04PROFILE ボタンの長押し
  5. 05出荷状態に戻す
  6. 06LED の意味
  7. 07電池を交換する

ボタンを押す

書き込み直後の状態では、ボタンに対応した文字の a・b・x・y が入力されます。

電源が入っていても、LED は通常消えています。

USB でつなぐ

  1. USB-C でつなぐつないでいる間は主に USB から給電されるため、電池はほとんど減りません。
  2. ボタンを押して入力するペアリングは不要です。

パソコンに USB でつないでいる間は、USB が優先されます

ワイヤレスでの入力と PROFILE ボタンは使えません。ワイヤレスで使うときは USB を抜きます。充電器やモバイルバッテリーから電源だけをとるときは、この制限はありません。

ワイヤレスでつなぐ

スマホやパソコンの Bluetooth 設定からペアリングします。LED の色の意味は「LED の意味」をご覧ください。

  1. USB を抜く
  2. 電源スイッチを ON にするつまみを、基板の ON の印字側へ動かします。LED が、いま選ばれている接続先の番号の回数だけ点滅します。
  3. 空いている接続先を選ぶLED が白く点滅すれば、その番号は空いています。青く点滅したときは別の機器が登録済みなので、PROFILE ボタンを短く押して、白く点滅する番号に切り替えます。黄色く点滅したときは電池が少なく色を見分けられないため、先に電池を交換します。
  4. つなぎたい機器の Bluetooth 設定を開く一覧に GC-ABXY- で始まる名前（例: GC-ABXY-3F7A）が表示されます。末尾の 4 文字は本体ごとに異なります。この名前を選んでペアリングします。
  5. ペアリングできたことを確かめるLED に 6 色が流れれば完了です。

接続先を切り替える

PROFILE ボタンを短く押すと、接続先が 1 → 2 → 3 → 1 と変わり、新しい番号の回数だけ LED が点滅します。

PROFILE ボタンの長押し

押し続けた時間でできることが変わります。LED を見ながら、目的の段階で離します。PROFILE を押している間は、A・B・X・Y を押しても入力されません。

0 秒

5 秒より前に離すと、接続先が次の番号に切り替わります

離したときに、新しい番号の回数だけ点滅します。

5 秒

5 秒を過ぎ、8 秒より前に離すと、操作は取り消されます

赤が点滅
8 秒

8 秒を過ぎてから離すと、いま選んでいる番号のペアリングを消します

赤が点灯

8 秒を過ぎたら取り消せません。消した番号は白く点滅し、新しい機器とペアリングできるようになります。相手側の機器にも接続情報が残っているので、そちらからも GC-ABXY-… の登録を削除してください。

10 秒X と Y も押す

X と Y も押していると、出荷状態に戻す操作になります

6 色が流れる

手順は「出荷状態に戻す」をご覧ください。

出荷状態に戻す

本体に保存されている接続先の情報と、キーの割り当てが消えます。

  1. USB を抜く
  2. 電源スイッチを ON にする
  3. PROFILE ボタンと X・Y を押し続けるPROFILE を先に押すと、x・y の文字が入力されません。5 秒で赤の点滅に変わります。X・Y を押している間は、8 秒を過ぎても赤の点灯にはならず、点滅が続きます。
  4. 6 色が流れ出したら（10 秒）、X と Y は押したまま PROFILE だけ離す再起動して、白が 1 回点滅すれば完了です（電池が残り少ないときは黄色）。

LED の意味

光り方意味
青が数回点滅 電源を入れたときと、接続先を切り替えたときに点滅します。回数が接続先の番号（1〜3）で、その番号は登録済みです。
白が数回点滅 青と同じ合図で、その番号は空いています（ペアリングできます）。
黄が数回点滅 同じ合図ですが、電池が残り少ないことを表します。使用中も 1 時間おきに知らせます。
6 色が 2 周（約 1 秒） ワイヤレスでつながりました。
赤の点滅・点灯、6 色が流れ続ける PROFILE ボタンの長押しの途中です。
マゼンタが点滅 診断の開始を待っています（診断する）。PROFILE と A を 3 秒押し続けると診断が始まります。30 秒経過すると元に戻ります。
マゼンタが 5 秒おきに光る 診断中です（キーを記録しています）。5 分経過するか、診断のページで終了すると元に戻ります。

電池を交換する

使えるのは CR2450 だけです。充電池（LIR2450）は使えません。

用意するもの: 硬貨と、プラスチック製のピンセット（金属製は電池をショートさせるおそれがあります）。

背面ケース側から見た向きです。同じ矢印と OPEN／CLOSE は基板に印刷してあり、透明な背面ケース越しに見えます。

  1. 電源スイッチを OFF にする設定の保存中に電池を外すと、設定が壊れるおそれがあります。
  2. 電池ぶたを反時計回りに回して外す硬貨などで回します。
  3. 古い電池をピンセットで取り出す電池のふちを片側だけ挟み、持ち上げます。
  4. ＋（印字のある広い面）を上にして入れる
  5. 電池ぶたを戻し、時計回りに止まるまで回す硬貨などで回します。

残量は接続した機器の画面にも表示されますが、電圧から推定した値のため、±20 % ほどずれることがあります。黄色く点滅したら交換してください。
