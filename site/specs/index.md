# 仕様

GC ABXY の大きさ・接続・電源・ファームウェアの一覧です。

## 本体

- **キー**: A・B・X・Y の 4 キー（最初は a・b・x・y）と、接続先の切り替え用の PROFILE ボタン
- **背面ケースの外形**: 直径 54.0 mm、高さ 11.9 mm の円筒形
- **基板**: 直径 48.4 mm の丸い基板
- **基板の版**: REV A（基板の、部品を付けた面に gc-abxy REV A と印字）。この取説は REV A に合わせています
- **ケースの材料**: 背面ケースは透明レジン（光造形）、電池ぶた・つまみ・キャップは PETG
- **状態表示**: XIAO の LED（赤・緑・青の組み合わせ）を、透明な背面ケース越しに見る設計

## 接続

- **通信規格**: USB（HID）、Bluetooth® Low Energy（HID over GATT）。無線は別途ご用意いただく XIAO nRF52840 のもので、キットに無線モジュールは含みません
- **USB**: USB-C（XIAO の端子）。キーボードとして認識され、ペアリングは不要です
- **ワイヤレス**: 3 台まで登録し、PROFILE ボタンで切り替え
- **優先順位**: パソコンに USB でつないでいる間は USB を優先（ワイヤレスには入力しません）
- **機器名**: GC-ABXY-XXXX（末尾 4 文字は本体ごとに決まる英数字）

## 電源

- **電池**: CR2450 ×1（充電池 LIR2450 は使えません）

## ファームウェア

- **もとにしたもの**: ZMK v0.3.0
- **書き込み方式**: UF2 ブートローダー（USB ドライブとして表示され、ファイルをコピーするだけ。専用ソフト不要）
- **キーの割り当て**: ZMK Studio（ブラウザで変更。USB 接続、Chrome・Edge）
- **診断機能**: 状態・起動回数・キー入力の記録をブラウザで読み出し（Windows・Mac・Android の Chrome、Windows・Mac の Edge）
- **ライセンス**: MIT（ソースは GitHub で公開）
