取扱説明書GC ABXY
ホーム ビルドガイド 使い方 困ったとき

仕様

GC ABXY の大きさ・接続・電源・ファームウェアの一覧です。

本体

キーA・B・X・Y の 4 キー（最初は a・b・x・y）と、接続先の切り替え用の PROFILE ボタン
背面ケースの外形直径 54.0 mm、高さ 11.9 mm の円筒形
基板直径 48.4 mm の丸い基板
基板の版REV A（基板の、部品を付けた面に gc-abxy REV A と印字）。この取説は REV A に合わせています
ケースの材料背面ケースは透明レジン（光造形）、電池ぶた・つまみ・キャップは PETG
状態表示XIAO の LED（赤・緑・青の組み合わせ）を、透明な背面ケース越しに見る設計

接続

通信規格USB（HID）、Bluetooth® Low Energy（HID over GATT）。無線は別途ご用意いただく XIAO nRF52840 のもので、キットに無線モジュールは含みません
USBUSB-C（XIAO の端子）。キーボードとして認識され、ペアリングは不要です
ワイヤレス3 台まで登録し、PROFILE ボタンで切り替え
優先順位パソコンに USB でつないでいる間は USB を優先（ワイヤレスには入力しません）
機器名GC-ABXY-XXXX（末尾 4 文字は本体ごとに決まる英数字）

電源

電池CR2450 ×1（充電池 LIR2450 は使えません）

ファームウェア

もとにしたものZMK v0.3.0
書き込み方式UF2 ブートローダー（USB ドライブとして表示され、ファイルをコピーするだけ。専用ソフト不要）
キーの割り当てZMK Studio（ブラウザで変更。USB 接続、Chrome・Edge）
診断機能状態・起動回数・キー入力の記録をブラウザで読み出し（Windows・Mac・Android の Chrome、Windows・Mac の Edge）
ライセンスMIT（ソースは GitHub で公開）

GitHub（ファームウェア） ・ 問い合わせ ・ 仕様 ・ 開発記 ・ 販売者: naritaku
