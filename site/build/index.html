組み立て

カプセルトイを分解し、はんだ付けした基板をケースに組みます。

カプセルトイを分解する

載せ替える最小限の部品だけ取り除きます。

手順 1
  1. もとの背面ケースのねじ 3 本を外す
  2. もとの背面ケースを取り外す
  3. 中枠を取り出す中枠は背面ケースと一緒に外れやすいです。一緒に外れなかったときは、中枠も取り外します。

外したものは、カプセルトイの状態に戻すときのためにまとめて保管してください。戻すときは、この逆の順で中枠ともとの背面ケースを載せ、もとのねじ 3 本で留めます。

ケースに組む

裏返したボタン面のケースの上に、部品を重ねていきます。

手順 1
  1. ゴムシートがはまっているか確かめるゴムシートのふちが浮かずに、ケースに沿っているか確かめます。
    浮いているときは、A ボタンと B ボタンの間の小さな穴に、ケースの細いピンが通っていること（動画の黄色い輪）を確かめてから、指でふちをなぞってはめ込みます。
  2. 基板を載せるはんだ付けした面を上側にし、ボタン面側ケースの柱に基板の穴を通すように載せます。
  3. スライドスイッチ用つまみをかぶせるスライドスイッチに、つまみを上からかぶせます。
  4. タクトスイッチ用キャップをかぶせる2 本の脚でスイッチの本体を挟むように、上からかぶせます。スイッチの真ん中に載っていることを確かめます。
  5. 背面ケースをかぶせる背面ケースの USB の切り欠きを XIAO の USB 端子に合わせ、ねじ穴やスイッチのつまみの位置に注意してかぶせます。
  6. 背面ケース側から、ねじを 3 本締める3 本とも軽く仮留めしてから順に締めます。締めすぎると、ボタンが沈みきらなくなります。

機構を確かめる

うまく動かないときは、部品がパッドに対してまっすぐはんだ付けされているか、キャップやつまみがまっすぐはまっているか、ねじを締めすぎていないかを確かめます。

手順 1

背面ケース側から見た図です。1PROFILE ボタン2電源スイッチ（基板に ON / OFF の印字）

  1. PROFILE ボタンが押せるか背面ケースの丸いくぼみの中の六角形のキャップを爪で押します。カチッと手応えがあり、離すと戻れば正常です。
  2. 電源スイッチのつまみがスライドするかON 側と OFF 側へ往復させます。引っかからずに動き、両端で止まれば正常です。
  3. ボタン面の A・B・X・Y が押せるか4 つとも、沈んで戻れば正常です。特定のボタンだけ硬いときは、ゴムシートの浮きか、ねじの締めすぎが考えられます。

電池を入れて電池ぶたを閉める

手順 1

背面ケース側から見た図です。1電源スイッチのつまみ

  1. 電源スイッチを OFF にするつまみを、基板の OFF の印字側へ動かします。
  2. 電池を入れる＋（印字のある広い面）を上にして入れます。
  3. 電池ぶたを閉める電池ぶたをはめ、硬貨などで時計回りに止まるまで回します。
