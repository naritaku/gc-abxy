# はんだ付け

はんだ付けは **20〜40 分**、初めての方は 1 時間ほどかかる見込みです。

## はんだ付けする

**小さい部品がすでに付いている面**にはんだ付けします。  
**基板はふちを持ち**、ボタンとの接点部分には素手で触れないようにします。

（図: 横から見た組み立ての様子）

（図: 基板の、ボタンとの接点の面。くし形の金色の接点が 4 か所）

1. **XIAO を付ける**
   USB 端子が基板のふちからはみ出す向きで、XIAO の USB と反対側（アンテナ側）の端を、白い線の端に合わせます。左右 **14 本の足すべて**をはんだ付けします。
2. **電池ホルダーを付ける**
   両側の足を、たっぷりのはんだで留めます。
3. **スライドスイッチを付ける**
   **6 本の足すべて**をはんだ付けします。
4. **タクトスイッチを付ける**
   4 本の足を四角いパッドに合わせ、**すべて**はんだ付けします。
5. **ボタンとの接点部分を確かめる**
   フラックスやはんだくずが付いていたら、無水エタノールを含ませた綿棒で拭きます。

## はんだ付けの確認

電池を入れる前に、テスターを導通（ブザー）モードにして、電源がショートしていないことと、スイッチが働くことを確かめます。

### ショートしていないことの確認（鳴らないこと）

スライドスイッチを、基板の **ON** の印字側にしておきます。

（図: はんだ付けを終えた基板を真上から見た図。スライドスイッチは ON 側。テスターを当てる場所に印を付けている）

（図: はんだ付けを終えた基板を真上から見た図。スライドスイッチは OFF 側。テスターを当てる場所に印を付けている）

1. **電池ホルダーの＋の端子と−の端子が鳴り続けないか**
   当てた瞬間に一瞬だけ鳴ることがありますが、正常です。鳴り続けたら、電池ホルダーとスライドスイッチの足のまわりで、はんだがつながっていないか確かめます。
2. **タクトスイッチの PROFILE の足と XIAO の `GND` が鳴らないか**
   PROFILE の足は、タクトスイッチの XIAO 側の上の足です。鳴ったら、タクトスイッチの足どうしがはんだでつながっています。はんだ吸い取り線で余分なはんだを取ります。
3. **スライドスイッチを OFF 側にして、電池ホルダーの＋の端子と図の `BAT` の穴が鳴らないか**
   鳴ったら、スライドスイッチの足どうしがはんだでつながっています。はんだ吸い取り線で余分なはんだを取ります。
4. **XIAO の隣り合う足どうしが鳴らないか**
   左右の列それぞれで、上から順に隣の足と当てていきます。当てた瞬間に一瞬だけ鳴ることがありますが、正常です。鳴り続けたら、その 2 本の足のあいだではんだがつながっています。はんだ吸い取り線で余分なはんだを取ります。

### 導通の確認（鳴ること）

スライドスイッチを **ON** 側に戻します。

（図: はんだ付けを終えた基板を真上から見た図。スライドスイッチは ON 側。テスターを当てる場所に印を付けている）

1. **電池ホルダーの＋の端子と図の `BAT` の穴が鳴るか**
   鳴らなければ、電池ホルダーの＋の足か、スライドスイッチの足のはんだが足りません。
2. **電池ホルダーの−の端子と XIAO の `GND` が鳴るか**
   鳴らなければ、電池ホルダーの−の足か、XIAO の `GND` の足のはんだが足りません。
3. **タクトスイッチを押しながら、PROFILE の足と XIAO の `GND` が鳴るか**
   鳴らなければ、PROFILE の足か、反対側の下の足のはんだが足りません。

確認が終わったら、基板のスライドスイッチを **OFF** の印字側にしておきます。
