# 困ったとき

うまく動かないときは、症状の表から探してください。購入前・製作前の質問は、ホームの「[よくある質問](https://gc-abxy.pages.dev/#faq)」をご覧ください。

## 症状から探す

| 症状 | 試すこと（上から順に） |
| --- | --- |
| USB でつなぐと XIAO が熱い<br>パソコンが認識しない | 1. **すぐ USB を抜き、電池も外す**。<br>2. 背面ケースを外し、[はんだ付けの確認](https://gc-abxy.pages.dev/solder/#solder-check)の「ショートしていないことの確認」をやり直す。鳴り続けたら、つながっているはんだを吸い取り線で直す。<br>3. 熱くならず、認識だけされないときは、**データが通る別のケーブル**と別の USB ポートで試す。 |
| まったく反応しない<br>LED も光らない | 1. 電源スイッチを **ON**（基板の ON の印字側）にする。<br>2. 電池の向きを確かめる（**＋の印字面が上**）。<br>3. 電池を**新しい CR2450** に替える。<br>4. USB でパソコンにつなぐ。動けば、電池ホルダーとスライドスイッチのはんだ付けを確かめる。動かなければ、**データが通る別のケーブル**と別の USB ポートで試す。<br>5. ゼムクリップなど先の細い物で**リセットボタンを 1 回**押す（再起動します）。<br>6. プログラムを[書き込み直す](https://gc-abxy.pages.dev/firmware/#flash)。 |
| つまみが重い・動かない | 1. ねじを少しゆるめる。<br>2. ケースを開け、つまみがスライドスイッチにかぶさっているか確かめる。 |
| 一部のボタンが反応しない | 1. ねじを少しゆるめる（締めすぎるとボタンが沈みきりません）。<br>2. ケースを開け、ゴムシートがボタン面のケースにぴったりはまっているか確かめる。<br>3. ゴムシート裏の黒い円を、乾いた柔らかい布で軽く拭く。<br>4. 基板のボタンとの接点部分にフラックスやはんだくずが付いていたら、無水エタノールを含ませた綿棒で拭く。<br>5. [診断](https://gc-abxy.pages.dev/help/#diag)で押した回数を確かめる。 |
| PROFILE ボタンが反応しない | 1. パソコンにつないだ USB ケーブルを抜く。<br>2. マゼンタ（赤紫）に光っているなら診断中です。[診断する](https://gc-abxy.pages.dev/help/#diag)で「終了」を押すか、電源を入れ直す。そのまま待っても、点滅なら 30 秒、5 秒おきに光るなら 5 分で元に戻ります。<br>3. 押しても手応えがないなら、背面ケースを外し、キャップがスイッチの真ん中に載っているか確かめる。 |
| ZMK Studio に GC-ABXY が表示されない | 1. パソコンの **Chrome か Edge** で開いているか確かめる（スマホや Safari・Firefox では使えません）。<br>2. **データが通るケーブル**で USB につなぎ直して、「USB」を押し直す。<br>3. プログラムを[書き込み直す](https://gc-abxy.pages.dev/firmware/#flash)。 |
| ペアリングできない<br>一覧に表示されない | 1. 黄色く点滅するなら、先に電池を[交換](https://gc-abxy.pages.dev/use/#battery)する（白と青が見分けられません）。<br>2. **USB を抜いて**、PROFILE を短く押して**白く点滅する番号**にする。3 つとも青なら、**使わない番号に切り替えて** PROFILE を[赤く点灯するまで長押し](https://gc-abxy.pages.dev/use/#profile-hold)して離し、その番号を空ける（登録が消えます）。<br>3. 機器側に古い **GC-ABXY**-… の登録が残っていれば削除する。<br>4. 機器の Bluetooth 設定をいったんオフにして、オンに戻す。<br>5. [出荷状態に戻して](https://gc-abxy.pages.dev/use/#reset)、つなぎ直す。 |
| スマホにつなぐと<br>画面のキーボードが表示されない | 故障ではありません。**iPhone・iPad**: 入力欄を選ぶと表示されるバーの、キーボードのボタン（∨）を押す。**Android**: 設定 → システム → 言語と入力 → 物理キーボード →「画面キーボードの使用」をオン（機種によって項目名が異なる）。 |
| Mac で「キーボード設定アシスタント」が開く | 閉じる（このキーパッドでは設定を完了できない）。入力には影響しない。 |
| つながったり切れたりする | 1. 黄色く点滅するなら電池を替える。<br>2. 機器に近づける（間に金属や体を挟まない）。<br>3. 機器側の登録を削除して、つなぎ直す。 |
| 別の機器に入力される | 1. パソコンに USB でつないでいると、そちらに入ります。ワイヤレスで使うなら USB を抜く。<br>2. PROFILE を短く押して、つなぎたい機器の番号にする（点滅の回数が番号）。 |
| 1 回押すと 2 回入る | 1. ケースを開け、ゴムシート裏の黒い円を、乾いた柔らかい布で軽く拭く。<br>2. [診断](https://gc-abxy.pages.dev/help/#diag)で、そのキーの押した回数と間隔の最短を確かめて、結果を添えて問い合わせる。 |
| 黄色く点滅する | 電池が残り少ない合図です。新しい CR2450 に[交換](https://gc-abxy.pages.dev/use/#battery)する。 |
| 上のどれでも直らない | 1. [出荷状態に戻す](https://gc-abxy.pages.dev/use/#reset)（ペアリングと割り当てが消えます）。<br>2. プログラムを[書き込み直す](https://gc-abxy.pages.dev/firmware/#flash)。<br>3. [診断して](https://gc-abxy.pages.dev/help/#diag)、結果とバージョンを添えて[問い合わせる](https://gc-abxy.pages.dev/help/#contact)。 |

## 診断する

本体の状態と、キーがどう押されたかをこのページで調べられます。Windows・Mac・Android の **Chrome**、または Windows・Mac の **Edge** で使えます。

> USB を抜き、PROFILE を短く押して**白く点滅する番号**にします。  
> つないだあと OS の画面でペアリングを求められたら「キャンセル」します。  
> 終わったら USB を抜き、PROFILE を短く押して、いつも使う番号に戻します。
>
> キーの記録は、本体の操作で開始したときだけ行い、最長 5 分で終わります。  
> 結果には、本体の個体 ID・起動回数・電池などの状態と、キーごとの押した回数・間隔の最短・押した長さの最長が含まれます。いつ押したか、何を入力したかは含まれません。

### 1. つないで状態を確かめる

1. **「つなぐ」を押す**
2. **一覧から GC-ABXY- で始まる名前を選び、「ペア設定」または「接続」を押す**
   バージョン・電池・起動回数・直前の再起動の理由が下に表示されます。

### 2. キーを確かめる

1. **「キーの確認を始める」を押す**
   本体の LED がマゼンタ（赤紫）で点滅します。
2. **本体の PROFILE と A を同時に 3 秒押し続ける**
   「キーの確認を始める」を押してから 30 秒以内に押します。3 秒より前に離したら、もう一度押し続けます。この間 PROFILE を押しても、接続先は切り替わりません。
3. **A・B・X・Y・PROFILE を 5 回ずつ押す**
   ふつうの速さで、1 回ずつ離して押します。表の回数が 5 になり、判定がすべて「OK」になれば正常です。

### 3. 結果をコピーして終える

「終了」を押すと記録をやめ、本体から消して、接続を切ります。押し忘れても、5 分経過するか電源を切ると、記録は終わります。

## 部品をなくした・壊したとき

なくしたり壊したりしたときは、次の条件に合うものを購入して使ってください。

| 部品 | 代わりに使えるもの |
| --- | --- |
| 電池ホルダー<br>CH274-2450LF | 同じ外形の表面実装ホルダーを使います（例: マルツオンラインの GB-BHH-2450RS-MS）。<br>外形は 36.1×16 mm、高さは 7.5 mm、端子の間隔は 33.3 mm です。 |
| スライドスイッチ<br>SSSS213202 | 足の配置が同じものを使います。<br>つまみは 1.5 mm 角、基板からつまみの先までは 5.8 mm、動く幅は 2 mm です。 |
| タクトスイッチ<br>TS-06104 | 6×6 mm、高さ 4.3 mm の表面実装品を使います（例: マルツオンラインの TVDM04-4.3-180GF）。 |
| 背面ケース・電池ぶた・つまみ・キャップ | [問い合わせ](https://gc-abxy.pages.dev/help/#contact)てください |
| M2×8 ねじ | 長さ 8 mm の M2 なべ小ねじを使います。 |
| ゴムシート・ボタン | 同じカプセルトイのものと入れ替えます。 |
| XIAO nRF52840 | 無印の 102010448 を使います（Sense や Plus は動作未確認です）。 |
| 電池 | CR2450 を使います。充電池（LIR2450）は使えません。 |

## バージョンを確かめて問い合わせる

問い合わせの前に、プログラムのバージョン（例: `v0.1.0`）を確かめてください。Windows・Mac と Android では、[診断する](https://gc-abxy.pages.dev/help/#diag)でつなぐと表示されます。iPhone などでは、下のアプリで読みます。

> 診断と同じく、USB を抜いて白く点滅する番号にしてから読みます。3 つとも青のときは、いまの番号の機器の Bluetooth を一時的にオフにします。

### スマホのアプリ nRF Connect で読む

Nordic Semiconductor の無料アプリ **nRF Connect for Mobile** を App Store か Google Play から入れます。

1. **アプリを開き、「SCANNER」（スキャン）の一覧から GC-ABXY- で始まる名前を探して「CONNECT」を押す**
   見つからないときは、下に引いて一覧を更新します。
2. **「Device Information」を開き、「Firmware Revision String」の値を確かめる**
   値が表示されていなければ、行の読み込みボタン（下向き矢印や「R」）を押します。これがバージョンです。
3. **「DISCONNECT」を押して切る**

### 問い合わせる

問い合わせは [gc-abxy.pages.dev/support](https://gc-abxy.pages.dev/support) で受け付けています。GitHub の Issues（問い合わせの掲示板）に移ります。書き込むには GitHub のアカウントが要り、**書いた内容は誰でも見られます**。住所や本名は書かないでください。

次のものを添えてください。

- **バージョン**（上で確かめたもの）
- **基板の版**（基板の、部品を付けた面の印字。例: `gc-abxy REV A`）
- **基板の両面の写真**
- **つなぎたい機器と OS**
- **LED の光り方**
- **診断の結果**（[診断する](https://gc-abxy.pages.dev/help/#diag)でコピーしたもの）
- **試したこと**
