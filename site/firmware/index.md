# プログラムの書き込み

組み立てが終わったら、パソコンにつないでプログラム（ファームウェア）を書き込みます。

## プログラムを書き込む

（図: 背面ケース側から見た完成品。USB 端子の左に XIAO のリセットボタン）

（図: Chrome で gc-abxy.pages.dev/fw を開いたところ。右上のダウンロード表示に gc-abxy.uf2（416 KB・完了））

（図: Mac の Finder。左の「場所」に XIAO-SENSE が表示され、中に CURRENT.UF2 など 3 つのファイルがある）

（図: gc-abxy.uf2 を、右のウインドウから左の XIAO-SENSE のウインドウへドラッグしているところ）

（図: テキストエディットに abxy と入力されたところ）

背面ケース側から見た図です。ケースの外からでも、先の細い物でリセットボタンを押せます。 1: リセットボタン。

Mac の Chrome の例です。右上に `gc-abxy.uf2` のダウンロードが表示されます。

Mac の Finder の例です。左の「場所」に **XIAO-SENSE** が表示されます。

`gc-abxy.uf2` を、**XIAO-SENSE** のウインドウへドラッグしているところです。

Mac のテキストエディットの例です。`a` `b` `x` `y` と入力されています。

1. **ファイルをパソコンに保存する**
   [gc-abxy.pages.dev/fw](https://gc-abxy.pages.dev/fw) を開くと、最新の `gc-abxy.uf2` がダウンロードされます。自動で始まらないときは、[リリースページ](https://gc-abxy.pages.dev/releases)（GitHub）から `gc-abxy.uf2` をダウンロードします。
2. **USB でパソコンにつなぐ**
   **データが通る USB-C ケーブル**を使います。充電専用のケーブルでは書き込めません。
3. **リセットボタンを素早く 2 回押す**
   **ゼムクリップなど先の細い物**で**リセットボタン**（図の **1**）を、**0.5 秒以内に 2 回**押します。
4. **ドライブが表示されたか確かめる**
   `XIAO-SENSE` か `XIAO-BLE` の名前で、USB メモリと同じように表示されます。どちらでも正常です。
5. **`gc-abxy.uf2` をドライブにドラッグする**
   コピーが終わると自動で再起動し、ドライブは消えます。Mac で「ディスクの不正な取り出し」や「エラーコード -36」が表示されても正常です。
6. **キーボードになったか確かめる**
   メモ帳などを開き、日本語入力をオフ（英数）にしてから 4 つのボタンを押します。`a` `b` `x` `y` と入力されれば正常です。
7. **USB を抜いて、電源スイッチを ON にする**
   つまみを、基板の **ON** の印字側へ動かします。**LED が白く 1 回点滅すれば完成です**（電池が残り少ないときは黄色）。

（図: Mac のダイアログ。gc-abxy.uf2 の一部のデータを読み込めないか書き込めないため、操作を完了できません（エラーコード -36））

手順 5 のあと Mac で表示されることがあるダイアログです。書き込みは終わっているので、**OK** を押して閉じます。

> ### うまく書き込めないときは
>
> **ドライブが表示されない**: USB を抜いて 10 秒待ち、挿し直してから、もう一度リセットを 2 回押します。
>
> **コピーしてもドライブがすぐにまた表示される**: 書き込めていません。入れたファイルが `gc-abxy.uf2` であることを確かめて、もう一度入れます。

## キーの割り当てを変える（任意）

4 つのボタンで入力するキーは、Web サイトの [ZMK Studio](https://zmk.studio/) で変えられます。

（図: ZMK Studio の最初の画面。USB ボタンが 1 つだけある）

（図: ブラウザの接続の画面。GC-ABXY の行を選び、接続ボタンを押す）

（図: ZMK Studio でキーを編集する画面。中央に 4 つのキー、下に Key 欄、右上に保存ボタン）

（図: ZMK Studio の画面。右上の保存ボタン）

最初の画面です。**USB** を押します。

「USB」を押すと表示される画面です（Mac の Chrome）。 1: GC-ABXY の行。 2: 接続。ほかの行の名前はパソコンによって違います。

B を ←（LeftArrow）に、A を → に変えた画面です。 1: 変えたいキー。 2: Key 欄。

3: 保存ボタン。画面右上にあります。

1. **USB でパソコンにつなぐ**
2. **ZMK Studio を開く**
   パソコンの **Chrome か Edge** で [zmk.studio](https://zmk.studio/) を開きます。スマホや Safari・Firefox では使えません。
3. **「USB」を押し、GC-ABXY を選んで「接続」を押す**
   ブラウザが開く小さなウィンドウに、つないでいる機器の一覧が表示されます。
4. **画面上の変えたいキーを押し、下の Key 欄で新しいキーを選ぶ**
   **2** の欄に **enter** などと入力すると、候補が絞れます。
5. **右上の保存ボタンを押す**
   押さないと、電源を切ったときに元に戻ります。

> PROFILE ボタンは ZMK Studio に表示されず、割り当ても変更できません。変えた割り当てを最初に戻すには、画面上の **GC-ABXY** ▾ から **Restore Stock Settings** を押します。

[使い方へ](https://gc-abxy.pages.dev/use/)
