プログラムの書き込み

組み立てが終わったら、パソコンにつないでプログラム（ファームウェア）を書き込みます。

プログラムを書き込む

手順 1

背面ケース側から見た図です。ケースの外からでも、先の細い物でリセットボタンを押せます。1リセットボタン

  1. ファイルをパソコンに保存するgc-abxy.pages.dev/fw を開くと、最新の gc-abxy.uf2 がダウンロードされます。自動で始まらないときは、リリースページ（GitHub）から gc-abxy.uf2 をダウンロードします。
  2. USB でパソコンにつなぐデータが通る USB-C ケーブルを使います。充電専用のケーブルでは書き込めません。
  3. リセットボタンを素早く 2 回押すゼムクリップなど先の細い物でリセットボタン（図の 1）を、0.5 秒以内に 2 回押します。
  4. ドライブが表示されたか確かめるXIAO-SENSE か XIAO-BLE の名前で、USB メモリと同じように表示されます。どちらでも正常です。
  5. gc-abxy.uf2 をドライブにドラッグするコピーが終わると自動で再起動し、ドライブは消えます。Mac で「ディスクの不正な取り出し」や「エラーコード -36」が表示されても正常です。
  6. キーボードになったか確かめるメモ帳などを開いて 4 つのボタンを押し、a b x y と入力されれば正常です。
  7. USB を抜いて、電源スイッチを ON にするつまみを、基板の ON の印字側へ動かします。LED が白く 1 回点滅すれば完成です（電池が残り少ないときは黄色）。

うまく書き込めないときは

ドライブが表示されない: USB を抜いて 10 秒待ち、挿し直してから、もう一度リセットを 2 回押します。

コピーしてもドライブがすぐにまた表示される: 書き込めていません。入れたファイルが gc-abxy.uf2 であることを確かめて、もう一度入れます。

キーの割り当てを変える（任意）

4 つのボタンで入力するキーは、Web サイトの ZMK Studio で変えられます。

手順 1

最初の画面です。USB を押します。

「USB」を押すと表示される画面です（Mac の Chrome）。1GC-ABXY の行2接続ほかの行の名前はパソコンによって違います。

B を ←（LeftArrow）に、A を → に変えた画面です。1変えたいキー2Key 欄

3保存ボタン画面右上にあります。

  1. USB でパソコンにつなぐ
  2. ZMK Studio を開くパソコンの Chrome か Edge で zmk.studio を開きます。スマホや Safari・Firefox では使えません。
  3. 「USB」を押し、GC-ABXY を選んで「接続」を押すブラウザが開く小さなウィンドウに、つないでいる機器の一覧が表示されます。
  4. 画面上の変えたいキーを押し、下の Key 欄で新しいキーを選ぶ2 の欄に enter などと入力すると、候補が絞れます。
  5. 右上の保存ボタンを押す押さないと、電源を切ったときに元に戻ります。

PROFILE ボタンは ZMK Studio に表示されず、割り当ても変更できません。変えた割り当てを最初に戻すには、画面上の GC-ABXY ▾ から Restore Stock Settings を押します。
