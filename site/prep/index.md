# 準備

組み立ての前に、部品と道具をそろえます。  
はんだ付けから書き込みまで、慣れている場合は **1 時間**程度、初めての方は **2〜3 時間**かかる見込みです。

> キットの部品の不足や破損があるときは、**はんだ付けや組み立ての前に**、写真を添えて[問い合わせて](https://gc-abxy.pages.dev/help/#contact)ください。作業を始めてから見つかったものは、交換できないことがあります。

## 安全のために

- カプセルトイの改造は**ご自身の責任**で行ってください。改造後はメーカーの保証を受けられません。
- **はんだごてでのやけどに注意してください**。使わないときはこて台に置き、換気しながら作業してください。
- **XIAO（無線モジュール）を削ったり曲げたりしないでください**。改造すると電波法に触れるおそれがあります。
- **小さな部品があります**。なくさないように注意してください。

## 購入が必要な部品

- [ ] 「コントローラーボタンコレクション2 Nintendo」ゲームキューブ ABXY ボタン ×1カプセルトイです
- [ ] XIAO nRF52840 ×1無印の **102010448** を使います（Sense や Plus は動作未確認です）[SeeedPR](https://www.seeedstudio.com/Seeed-XIAO-BLE-nRF52840-p-5201.html?sensecap_affiliate=a6qWPmA&referring_service=link)[マルツ](https://www.marutsu.co.jp/pc/i/2240476/)[秋月](https://akizukidenshi.com/catalog/g/g117341/)
- [ ] CR2450 コイン電池 ×1家電量販店やホームセンターなどでも入手できます[マルツ](https://www.marutsu.co.jp/pc/i/164367/)

PR の付いたリンクはアフィリエイトリンクです。詳しくは[注記](https://gc-abxy.pages.dev/#legal-ad)をご覧ください。

> ### 電池は CR2450 だけを使ってください
>
> 充電池（LIR2450）は使えません。**故障や発熱の原因になります**。

> ### コイン電池は、子どもの手の届かないところに置いてください
>
> 飲み込むと、短い時間で食道や胃に重いやけどのような損傷を起こすおそれがあります。**飲み込んだおそれがあるときは、すぐに医療機関を受診してください**。
>
> 使い終わった電池は、テープで絶縁し、お住まいの自治体の区分に従って処分してください。

## 道具

- [ ] パソコンWindows・Mac・Linux に対応しています。プログラムの書き込みとキーの割り当てに使います
- [ ] USB-C ケーブルデータ通信ができるものを使います
- [ ] はんだごてとはんだ表面実装部品のはんだ付けに適した、細いこて先のものを使います
- [ ] 精密ドライバー（プラス）**#0**
- [ ] 硬貨電池ぶたの開け閉めに使います
- [ ] ゼムクリップなど先の細い物ケースの外からリセットボタンを押すときに使います（プログラムの書き込み）
- [ ] プラスチック製のピンセット電池を取り出すときに使います。金属製は電池をショートさせるおそれがあります
- [ ] テスターはんだ付けの確認に使います。導通（ブザー）モードのあるものを使います
- [ ] はんだ吸い取り線隣のパッドとつながってしまったときに、余分なはんだを吸い取ります
- [ ] 無水エタノールと綿棒はんだ付けのあと、ボタンとの接点を拭きます

## XIAO の動作を確かめる

ケーブルがデータ通信に対応しているか、パソコンが XIAO を認識するかを確かめるため、XIAO だけを USB でパソコンにつなぎます。  
リセットボタンを素早く 2 回押し、USB メモリと同じようなドライブが表示されれば正常です。

詳しくは [Seeed の公式ページ（英語）](https://wiki.seeedstudio.com/XIAO_BLE/)をご覧ください。
