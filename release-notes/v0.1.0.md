GC ABXY のファームウェアの最初の公開版です。

## 入手と書き込み

- ファイル: 下の **Assets** にある `gc-abxy.uf2`（https://gc-abxy.pages.dev/fw からも同じものをダウンロードできます）
- 書き込み方: 取扱説明書の「[プログラムの書き込み](https://gc-abxy.pages.dev/firmware/#flash)」を見てください。XIAO のリセットボタンを素早く 2 回押して表示されるドライブに、`gc-abxy.uf2` をドラッグします。

## この版でできること

- A・B・X・Y の 4 つのボタンで `a`・`b`・`x`・`y` を入力します。割り当ては [ZMK Studio](https://zmk.studio/)（パソコンの Chrome か Edge、USB 接続）で変えられます。
- USB とワイヤレスの両方で使えます。ワイヤレスの接続先は 3 つまで登録でき、PROFILE ボタンの短押しで切り替えます。
- PROFILE ボタンを押し続け、8 秒を過ぎてから離すと、選んでいる接続先の登録を消します。
- 背面の LED で、接続先の番号・ペアリングの状態・電池の残りを表します。
- 取扱説明書の「[診断する](https://gc-abxy.pages.dev/help/#diag)」で、本体の状態とキーの押され方を確かめられます。

使い方の詳細は [取扱説明書](https://gc-abxy.pages.dev/) を見てください。不具合や質問は [Issues](https://gc-abxy.pages.dev/support) へどうぞ。
